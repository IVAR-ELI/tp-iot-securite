# TP Securite IoT

Compte rendu de TP : parseurs Zigbee / Z-Wave / Home Assistant,
normalisation, filtre deadband, regles de detection, pseudonymisation HMAC,
entropie et MITRE.

- `tp_starter.py` : tout le code du TP (version finale)
- `lancer_pipeline.py` : lance le pipeline complet sur les gros fichiers
- `verif.py`, `sensibilite.py`, `attaque_dico.py`, `attaque_hmac.py`,
  `verif_8_4.py`, `verif_9_3.py`, `mesure_4_3.py`, `mesure_4_3_bis.py` :
  scripts de verification utilises dans le rapport

Les fichiers de donnees ne sont pas dans le depot : il faut les placer dans
un dossier `data/` a cote de `tp_starter.py`.
